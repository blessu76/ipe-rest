Мы говорим комментариями в коде

Перевод ИИ Эта страница — машинный перевод оригинала (английский / корейский), в нём возможны ошибки. Приоритет у оригинала. Читать оригинал

В ipe() самые тихие строки пишутся как комментарии в коде: комментарий не выполняется, не бывает заголовком и просто остаётся, когда всё остальное закончено.

В коде строка, начинающаяся с //, — это записка тому, кто будет читать дальше. Компьютер её пропускает. Из-за неё ничего не происходит, и всё же человек часто помнит именно её.

Этот голос мы выбрали для ipe(). Наш слоган // rest was written into the code — комментарий. Так же и строка, которая завершает треки, — единственный шёпот «ipe. be still.», — и короткие выделенные цитаты в записях этого журнала. Ни одна из них не просит ни во что верить и ничего делать.

Нам нравится, как мало требует комментарий. Он не прерывает программу и не соперничает с работой. Он ждёт, когда его прочтут, в темпе читателя, обычно тогда, когда тот замедлился.

Та же мысль определяет и облик студии: страница цвета бумаги, тёмные чернила, засечки в заголовках, моноширинный шрифт в метках // и редактор кода вместо мультяшного талисмана. Тихо по замыслу — чтобы у уставшего часа было место отдохнуть.

ipe(); // no need to run this line
