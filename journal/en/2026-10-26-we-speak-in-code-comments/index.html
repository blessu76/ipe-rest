We speak in code comments

At ipe(), the quietest lines are written as code comments: a comment does not run, it is not a headline, and it simply stays after everything else has finished.

In code, a line that starts with // is a note left for whoever reads next. The computer skips it. Nothing happens because of it, and yet it is often the part a person remembers.

That is the voice we chose for ipe(). Our slogan, // rest was written into the code, is a comment. So is the line that closes the tracks, the one whispered breath, “ipe. be still.”, and the short quotes set apart in these journal entries. None of them asks you to believe or to do anything.

We like how little a comment demands. It does not interrupt the program, and it does not compete with the work. It waits to be read, at the speed of the reader, usually when the reader has slowed down.

The same idea shapes how the studio looks: a paper-cream page, dark ink, a serif for headlines, a monospaced face for the // labels, and a code editor instead of a cartoon mascot. Quiet by design, so that the tired hour has somewhere to rest.
