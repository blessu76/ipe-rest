1. 책임자

ipe.rest 는 서울의 개인 Davy Kim (ipe Studio)이 운영합니다. 개인정보 보호책임자도 같은 사람이며, 이 방침이나 개인정보에 관한 문의는 ipe.haven@gmail.com 로 보내 주세요.

2. 수집하는 정보

방문 통계 (Google Analytics 4)

어떤 페이지가 읽히는지 보기 위해 Google Analytics 4 를 사용합니다. 페이지 조회, 유입 경로, 브라우저·기기 종류, 대략적인 위치(국가 또는 도시), 사이트 밖으로 나가는 링크 클릭(링크 주소만)을 기록합니다. 방문을 구분하기 위해 브라우저에 쿠키(예: _ga, 최대 2년)를 저장합니다. 분석 데이터에서 이름이나 이메일을 받지 않으며 이를 통해 개인을 알아볼 수 없습니다. 이 데이터는 Google 이 저희를 대신해 처리하며, 국외 서버에서 처리될 수 있습니다.

방문 통계 (Cloudflare Web Analytics)

홈 페이지에서는 Cloudflare Web Analytics 도 사용합니다. 쿠키를 쓰지 않고 개별 방문자를 사이트 간에 추적하지 않는 개인정보 친화적인 서비스로, 페이지 조회 수와 로딩 성능을 합산해서만 측정합니다.

리디렉션 페이지

스튜디오가 공유하는 일부 링크는 YouTube 로 가기 전에 짧은 안내 페이지를 거칩니다. 이 페이지는 어떤 트랙 코드가 열렸는지와 대략적인 경로(앱·SNS·기타)만 기록하며, 개인을 알 수 있는 글은 담지 않습니다.

이용자 브라우저에 저장되는 것

언어를 선택하면 그 선택을 브라우저 로컬 저장소에 ipe_lang 이라는 이름으로 저장합니다. 이 값은 이용자 기기에만 있고 저희에게 전송되지 않습니다. 또한 사이트를 빠르게 열고 오프라인에서도 쓸 수 있도록 사이트 파일의 캐시를 보관합니다. 둘 다 브라우저 설정에서 지울 수 있습니다.

보내 주신 이메일

ipe.haven@gmail.com 로 메일을 보내시면 이메일 주소와 본문에 적으신 내용을 받게 됩니다. 답장과 요청 처리에만 사용하며, 처리에 필요한 기간 동안 보관합니다. 언제든 삭제를 요청하실 수 있습니다.

호스팅

이 사이트는 GitHub Pages 에서 제공됩니다. 모든 호스팅이 그렇듯 IP 주소 같은 접속 기술 정보가 호스팅 사업자에 전달되며, 이에 대해서는 GitHub 의 개인정보 처리방침이 적용됩니다.

3. 이용 목적

무엇이 읽히는지 파악해 사이트를 개선하고, 보내 주신 메시지에 답하고, 사이트를 정상적이고 안전하게 운영하기 위해서입니다. 프로파일링에 쓰지 않으며 판매하지 않습니다.

4. 제공·위탁

위에서 밝힌 Google(통계), Cloudflare(통계), GitHub(호스팅)가 처리에 관여합니다. YouTube, Instagram, TikTok, SoundCloud, X, Facebook 으로 연결되는 링크는 각 서비스의 방침을 따릅니다. 법령에 따라 요구되는 경우를 제외하고 그 외 제3자에게 제공하지 않습니다.

5. 선택할 수 있는 것

  • 브라우저 설정에서 쿠키를 차단·삭제하거나 Google 의 Analytics 수신 거부 부가기능을 사용하실 수 있습니다. 쿠키가 없어도 사이트는 똑같이 동작합니다.
  • 사이트 데이터를 지우면 저장된 언어 설정과 오프라인 캐시가 삭제됩니다.

6. 열람·정정·삭제 요청

저희가 보유한 본인의 개인정보에 대해 열람, 정정, 삭제, 처리 정지를 요청하실 수 있습니다. 메일을 보내셨던 주소로 ipe.haven@gmail.com 에 요청해 주세요. 10일 이내에 답장드립니다. 분석 데이터는 이름이나 이메일과 연결되어 있지 않아 보통 개인을 찾아낼 수 없으며, 이메일 문의 내용은 찾아서 삭제해 드립니다.

7. 광고

ipe.rest 에는 광고가 없습니다. 앞으로 광고를 게재하게 되더라도 idle.ipe.rest 에만 표시되며, 그에 앞서 이 방침에 광고 파트너, 사용하는 쿠키, 거부 방법을 먼저 반영하겠습니다.
