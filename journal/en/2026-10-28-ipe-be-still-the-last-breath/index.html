The last breath of every track

Every ipe() track ends the same way: after the last note, one whispered line, “ipe. be still.” It is a single breath, and it is always in English.

The rule is short. The line sits at the very end, after the music has finished. It is spoken, not sung, and spoken quietly. Since the dear(you); album it has closed every track, and it does not change from one release to the next.

We keep it to one breath on purpose. A song can carry a story, but the last second can carry only one thing. The line explains nothing and asks for nothing; it is the pause you take once the work is done.

In code terms, it is the idle state: the program has finished, nothing is left to run, and the machine rests. That is where our name comes from, and the whisper is the same idea in sound.

ipe(); // be still

So if you listen late in the evening, let the track run all the way out. Leave that last second alone before you reach for the next one.
