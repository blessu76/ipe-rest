简要说明:本网站通过 Google Analytics 和 Cloudflare Web Analytics 收集基本的访问统计数据,将您的语言偏好记录在您自己的浏览器中,并且仅在您给我们写信时才保留您的电子邮件地址。本网站不展示广告,也不出售数据。

1. 责任主体

ipe.rest 由 Davy Kim(ipe Studio,首尔)以个人身份运营。关于本政策或您的信息的问题,请联系:ipe.haven@gmail.com。

2. 我们收集的信息

访问统计(Google Analytics 4)

我们使用 Google Analytics 4 来了解哪些页面被阅读。它会记录页面浏览量、您来自的页面、您的浏览器和设备类型、大致位置(国家或城市),以及对离开本网站的链接的点击(仅限链接地址)。它会在您的浏览器中设置 Cookie(例如 _ga,最长可保留两年)以区分不同的访问。我们不会在统计分析中要求您提供姓名或电子邮件,也无法据此识别您的身份。Google 代表我们处理这些数据,其中可能涉及位于韩国境外的服务器。

访问统计(Cloudflare Web Analytics)

主页还使用 Cloudflare Web Analytics,这是一项注重隐私的服务,不使用 Cookie,也不会跨网站追踪个别访问者。它统计页面浏览总量和页面加载性能。

跳转页面

工作室分享的部分链接在打开 YouTube 之前会经过一个简短的跳转页面。这些页面会记录打开的是哪个曲目代码以及大致来源(应用、社交媒体、其他)。其中不包含任何个人文字信息。

存储在您浏览器中的信息

当您选择语言时,我们会将该选择以 ipe_lang 为名保存在您浏览器的本地存储中。它保留在您的设备上,绝不会发送给我们。本网站还会缓存自身的文件,以便快速打开并支持离线使用。您可以在浏览器设置中清除这两项内容。

您发送给我们的电子邮件

如果您给 ipe.haven@gmail.com 写信,我们会收到您的电子邮件地址以及您在邮件中提供的任何内容。我们仅将其用于回复和处理您的请求,并在此所需的期限内保留。您可以随时要求我们删除。

托管

本网站托管在 GitHub Pages 上。与任何托管服务一样,它会接收诸如您的 IP 地址之类的技术性请求数据;对此适用 GitHub 自己的隐私声明。

3. 我们如何使用这些信息

用于了解哪些内容被阅读并改进本网站、回复您的留言,以及保持本网站正常运行和安全。我们不将其用于用户画像,也不出售。

4. 还有谁能看到这些信息

如上所述,包括 Google(统计分析)、Cloudflare(统计分析)和 GitHub(托管)。指向 YouTube、Instagram、TikTok、SoundCloud、X 和 Facebook 的链接会通向有各自政策的服务。除法律要求的情形外,我们不会与其他任何人分享您的信息。

5. 您的选择

  • 在浏览器设置中阻止或删除 Cookie,或使用 Google 的Analytics 停用浏览器插件。没有这些 Cookie,本网站的功能不受影响。
  • 清除网站数据即可删除您已保存的语言偏好和离线缓存。

6. 查阅与删除

您可以要求查阅、更正或删除我们持有的关于您的个人信息,或限制我们对其的使用。请使用您此前使用的邮箱地址写信至 ipe.haven@gmail.com。我们将在 10 日内答复。统计数据与您的姓名或电子邮件没有关联,因此我们通常无法从中找到某个个人;而电子邮件往来记录我们可以查找并删除。

7. 广告

ipe.rest 不展示广告。如果将来提供广告,将仅出现在 idle.ipe.rest 上,并且我们会先更新本政策,说明合作方、其使用的 Cookie 以及如何选择退出。

8. 儿童

本网站并非面向 14 岁以下儿童,我们不会有意收集他们的个人信息。

9. 投诉

如果您在韩国,也可以联系个人信息侵害申报中心(privacy.kisa.or.kr,118)或个人信息纠纷调解委员会(kopico.go.kr,1833-6972)。

10. 变更

如果本政策发生重要变更,我们将在此发布新版本并注明新的生效日期。当前版本:2026-10-20。
