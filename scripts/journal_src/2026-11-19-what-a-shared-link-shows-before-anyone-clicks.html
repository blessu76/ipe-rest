What a shared link shows before anyone clicks

링크를 공유하면 누르기 전에 보이는 것

When somebody pastes an address from ipe.rest into a chat, the app that receives it builds a small card, and what is on that card was decided here.

Three things on the card

A card has a title, a short description and a picture. The title is the entry's own title, without the site name that the browser tab adds at the end, so it reads cleanly in a narrow bubble. The description is the excerpt that was written for that entry, kept short enough not to be cut off. The picture is 1200 by 630 pixels and carries a short text description for readers who cannot see it. By default every entry uses the same picture, so the card looks like ipe() and nothing else. An entry can carry a picture of its own when it needs one.

In the language you linked

Each language page has its own title and description in its own language, and it tells the receiving app which language and region it belongs to and which other languages exist. If you link to the Korean page, the card is in Korean. If you link to the Japanese page, it is in Japanese. Nobody has to translate a card afterwards, because it is built from the same text as the page.

The address it points at

The address in the card is the page's own canonical address, the same one that search engines are told about. A link shared from the Japanese page stays the Japanese page, and the person who opens it lands where you were, not on a menu that asks them to choose again. The language chooser exists for visitors who arrive without a language, not for links that already have one.

No share tracking

All of this is plain text in the head of the page. There is no share button, no counter and no script that reports a share, and the page itself cannot tell that anybody pasted its address anywhere. The receiving app fetches the page the way any visitor would, and the site adds nothing to track who asked. What the host and the visit statistics record for any visit is described in the privacy policy.

When a card looks out of date

Chat apps keep a copy of a card for a while so that they do not have to ask again every time. If an entry is corrected and an old card still shows the earlier wording, the copy is theirs, not ours, and it usually fades by itself. The page is always right; only the card can be late.

A link is a small promise about what is on the other side. We would like the card to keep it.

누군가 ipe.rest 의 주소를 대화창에 붙이면 받는 앱이 작은 카드를 만들고, 그 카드에 무엇이 나올지는 여기서 정해 둔 것입니다.

카드에 나오는 세 가지

카드에는 제목, 짧은 설명, 그림이 있습니다. 제목은 글 자체의 제목이고, 브라우저 탭이 끝에 붙이는 사이트 이름은 뺐기 때문에 좁은 말풍선에서도 깔끔하게 읽힙니다. 설명은 그 글을 위해 쓴 발췌문이고, 잘리지 않도록 짧게 유지합니다. 그림은 1200×630 픽셀이고, 그림을 볼 수 없는 독자를 위한 짧은 글 설명이 붙어 있습니다. 기본적으로 모든 글이 같은 그림을 써서 카드는 ipe() 로만 보입니다. 필요한 글은 자기만의 그림을 가질 수 있습니다.

링크한 언어로

언어별 페이지는 자기 언어로 된 제목과 설명을 갖고, 받는 앱에게 어느 언어와 지역에 속하는지, 다른 어떤 언어가 있는지도 알려 줍니다. 한국어 페이지를 링크하면 카드는 한국어로 나오고, 일본어 페이지를 링크하면 일본어로 나옵니다. 카드는 페이지와 같은 글로 만들어지므로 나중에 누가 따로 번역할 일이 없습니다.

카드가 가리키는 주소

카드의 주소는 그 페이지의 고유(canonical) 주소로, 검색 엔진에 알려 둔 것과 같습니다. 일본어 페이지에서 공유한 링크는 일본어 페이지로 남고, 그것을 여는 사람은 다시 고르라고 묻는 메뉴가 아니라 당신이 있던 곳에 도착합니다. 언어 선택 페이지는 언어 없이 들어온 방문자를 위한 것이지, 이미 언어가 있는 링크를 위한 것이 아닙니다.

공유를 따로 추적하지 않습니다

이 모든 것은 페이지 머리에 있는 평범한 글입니다. 공유 버튼도, 카운터도, 공유를 보고하는 스크립트도 없고, 누군가 주소를 어딘가에 붙였는지 페이지 스스로는 알 수 없습니다. 받는 앱은 여느 방문자처럼 페이지를 가져가고, 사이트는 누가 물었는지 따로 추적하지 않습니다. 어떤 방문이든 호스팅과 방문 통계가 무엇을 기록하는지는 개인정보처리방침에 적혀 있습니다.

카드가 오래되어 보일 때

대화 앱은 매번 다시 묻지 않으려고 카드의 사본을 한동안 보관합니다. 글을 고쳤는데 옛 카드에 이전 문구가 남아 있다면 그 사본은 우리 것이 아니라 그쪽 것이고, 대개 저절로 사라집니다. 페이지는 언제나 맞고, 늦을 수 있는 것은 카드뿐입니다.
