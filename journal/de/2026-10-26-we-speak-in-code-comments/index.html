Wir sprechen in Code-Kommentaren

KI-Übersetzung Diese Seite ist eine maschinelle Übersetzung des Originals (Englisch / Koreanisch) und kann Fehler enthalten. Maßgeblich ist das Original. Original lesen

Bei ipe() werden die leisesten Zeilen als Code-Kommentare geschrieben: Ein Kommentar läuft nicht, ist keine Schlagzeile und bleibt einfach stehen, wenn alles andere fertig ist.

Im Code ist eine Zeile, die mit // beginnt, eine Notiz für die Person, die als Nächstes liest. Der Computer überspringt sie. Ihretwegen passiert nichts, und doch ist sie oft das, woran man sich erinnert.

Das ist die Stimme, die wir für ipe() gewählt haben. Unser Slogan // rest was written into the code ist ein Kommentar. Ebenso die Zeile, die die Tracks beschließt, das eine geflüsterte „ipe. be still.“, und die abgesetzten kurzen Zitate in diesen Journal-Einträgen. Keine davon verlangt, dass du etwas glaubst oder tust.

Wir mögen, wie wenig ein Kommentar verlangt. Er unterbricht das Programm nicht und konkurriert nicht mit der Arbeit. Er wartet darauf, gelesen zu werden, im Tempo des Lesers, meist dann, wenn dieser langsamer geworden ist.

Dieselbe Idee prägt, wie das Studio aussieht: eine papierfarbene Seite, dunkle Tinte, eine Serife für Überschriften, eine Monospace-Schrift für die //-Labels und ein Code-Editor statt eines Comic-Maskottchens. Leise by design, damit die müde Stunde einen Ort zum Ausruhen hat.
