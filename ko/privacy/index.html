02사이트가 쓰는 도구

  1. Google Analytics 4 (GA4) — 방문 수, 페이지 이용, 링크 클릭 같은 이용 통계를 봅니다. 쿠키(_ga, _ga_*)를 사용합니다. 사이트 ipe.rest 와 음악 사이트 idle.ipe.rest 는 같은 GA4 속성을 함께 사용합니다. 제공: Google LLC (Google Ireland Limited 등 계열사 포함).
  2. Cloudflare Web Analytics — 쿠키를 쓰지 않는 방식으로 페이지 조회 수와 성능 지표를 집계합니다. 제공: Cloudflare, Inc.
  3. GitHub Pages — 사이트 파일을 보관하고 전송합니다. 서버 접속 기록(IP 등)은 GitHub, Inc. 가 보안·운영 목적으로 처리할 수 있습니다.
  4. 브라우저 저장소 — 이용자의 선택(언어 ipe_lang)을 이용자 기기 안에만 저장합니다. 운영자 서버로 전송되지 않으며 브라우저에서 지울 수 있습니다. 오프라인에서도 열 수 있도록 서비스 워커가 페이지·아이콘 파일을 기기에 임시로 보관합니다.

사이트의 외부 링크(YouTube, Instagram, TikTok, SoundCloud, X 등)를 누르면 해당 서비스로 이동하며, 이동한 뒤의 정보 처리는 각 서비스의 정책을 따릅니다. 음악 사이트 idle.ipe.rest 는 별도의 개인정보처리방침을 따릅니다.

03쿠키와 유사 기술

이 사이트에서는 Google Analytics 가 쿠키를 사용합니다. 이용자는 브라우저 설정에서 쿠키를 허용·차단·삭제할 수 있습니다. 쿠키를 막아도 사이트는 이용할 수 있으나 언어 선택 저장은 되지 않을 수 있습니다. Google Analytics 차단 브라우저 부가기능으로도 거부할 수 있습니다.

04제3자 제공, 처리 위탁, 국외 이전

운영자는 이용자의 개인정보를 제3자에게 판매하거나 대가를 받고 제공하지 않으며, 법령에 근거가 있는 경우를 제외하고 이용자 동의 없이 제공하지 않습니다. 사이트가 쓰는 아래 서비스는 해외 서버에서 이용자의 브라우저와 직접 통신하며 제1항의 자동 수집 정보를 처리합니다. 이전은 사이트 접속 시 네트워크를 통해 자동으로 이루어집니다.

05개인정보의 보유 기간과 파기

  • 문의 메일: 처리 완료 후 1년이 지나면 지체 없이 파기합니다. 파기 방법은 메일함에서의 영구 삭제입니다.
  • 분석 도구가 보관하는 정보는 각 제공자의 보유 기간에 따릅니다 (제4항).
  • 보유 기간이 끝났거나 처리 목적이 달성된 개인정보는 복구할 수 없는 방법으로 파기합니다. 법령에 따라 보존해야 하는 정보는 다른 정보와 분리해 보관한 뒤 기간이 끝나면 파기합니다.

06이용자의 권리와 행사 방법

이용자는 언제든 운영자에게 자신의 개인정보에 대한 열람, 정정·삭제, 처리 정지, 동의 철회를 요청할 수 있습니다. {{CONTACT_EMAIL}} 로 요청하시면 지체 없이 처리하고 결과를 알려 드립니다. 대리인을 통한 요청도 가능합니다. 쿠키는 제3항의 방법으로 직접 거부할 수 있습니다. 다만 분석 도구가 쿠키 식별자로만 모은 정보는 운영자가 개인을 특정할 수 없어 열람·삭제 요청에 응하기 어려울 수 있으며, 이 경우 해당 제공자(Google 등)의 이용자 도구를 안내해 드립니다.

07만 14세 미만 아동

사이트는 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 알면서 수집하지 않습니다. 보호자께서 아동이 개인정보를 보냈다고 판단하시면 문의 메일로 알려 주세요. 즉시 삭제합니다.
