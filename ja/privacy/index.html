要点：当サイトは Google Analytics と Cloudflare Web Analytics を通じて基本的な訪問統計を収集し、お客様の言語設定をお客様自身のブラウザに記憶し、メールアドレスはお客様が私たちに連絡された場合にのみ保管します。広告は表示せず、データの販売も行いません。

1. 責任者

ipe.rest は、Davy Kim(ipe Studio、ソウル)が個人として運営しています。本ポリシーまたはお客様の情報に関するお問い合わせ：ipe.haven@gmail.com。

2. 収集する情報

訪問統計(Google Analytics 4)

どのページが閲覧されているかを把握するために Google Analytics 4 を使用しています。ページビュー、閲覧元のページ、ブラウザおよびデバイスの種類、おおよその所在地(国または都市)、当サイトから外部へ移動するリンクのクリック(リンク先アドレスのみ)を記録します。訪問を区別するため、お客様のブラウザにクッキー(最長2年間保持されることがある _ga など)を設定します。分析においてお客様のお名前やメールアドレスをお尋ねすることはなく、これによりお客様を特定することもできません。Google は当方に代わってこのデータを処理し、韓国国外のサーバーが含まれる場合があります。

訪問統計(Cloudflare Web Analytics)

ホームページでは Cloudflare Web Analytics も使用しています。これはプライバシーを重視したサービスで、クッキーを使用せず、サイトをまたいで個々の訪問者を追跡することもありません。ページビューの合計とページの読み込み性能を計測します。

リダイレクトページ

スタジオが共有する一部のリンクは、YouTube を開く前に短いリダイレクトページを経由します。これらのページには、どのトラックコードが開かれたかと、おおまかな流入元(アプリ、ソーシャル、その他)が記録されます。個人を特定する文言は含まれません。

ブラウザに保存される情報

言語を選択すると、その選択がブラウザのローカルストレージに ipe_lang という名前で保存されます。これはお客様の端末内に留まり、私たちに送信されることはありません。また、サイトを素早く開き、オフラインでも動作させるために、サイト自身のファイルのキャッシュも保持します。どちらもブラウザの設定で消去できます。

お送りいただくメール

ipe.haven@gmail.com にメールをお送りいただいた場合、お客様のメールアドレスと本文に含まれる内容を受け取ります。これは返信およびご依頼への対応にのみ使用し、そのために必要な期間保管します。いつでも削除を依頼できます。

ジャーナルのコメントといいね

ジャーナルの記事には「いいね」ボタンとコメント欄があります。コメントを投稿すると、入力されたニックネーム・コメント本文・投稿時刻を Google Firebase(Cloud Firestore、ソウルリージョン)に保存し、記事の下に公開します。メールアドレスやログインは求めません。「いいね」はその記事のカウンターに 1 を加えるだけで、個人は特定されません。重複を防ぐため、いいねした記事と最後にコメントした時刻はお使いのブラウザ(ローカルストレージ)にのみ記憶され、当方には送信されません。コメントには個人情報を書かないでください。コメントの削除をご希望の場合は上記の連絡先までご連絡ください。

ホスティング

当サイトは GitHub Pages 上でホストされています。他のホスティング事業者と同様に、IP アドレスなどの技術的なリクエストデータを受信します。これには GitHub 自身のプライバシーに関する声明が適用されます。

3. 利用目的

閲覧されている内容を把握してサイトを改善すること、メッセージに返信すること、サイトの動作と安全性を維持することです。プロファイリングには使用せず、販売もしません。

4. 情報を見る第三者

上記のとおり、Google(分析)、Cloudflare(分析)、GitHub(ホスティング)です。YouTube、Instagram、TikTok、SoundCloud、X、Facebook へのリンクは、それぞれ独自のポリシーを持つサービスにつながります。法律で求められる場合を除き、お客様の情報をそれ以外の第三者と共有することはありません。

5. お客様の選択

  • ブラウザの設定でクッキーをブロックまたは削除するか、Google のAnalytics オプトアウトアドオンをご利用ください。クッキーがなくてもサイトは同じように動作します。
  • サイトデータを消去すると、保存された言語設定とオフラインキャッシュが削除されます。

6. 開示と削除

当方が保有するお客様の個人情報について、閲覧、訂正、削除、または利用の制限を求めることができます。ご利用のアドレスから ipe.haven@gmail.com 宛にご連絡ください。10日以内に返信します。分析データはお客様のお名前やメールアドレスと結び付いていないため、通常、その中から個人を特定することはできません。メールのやり取りは、特定して削除することができます。

7. 広告

ipe.rest には広告は表示されません。将来広告が提供される場合は idle.ipe.rest にのみ表示され、その前に本ポリシーを更新して、提携先、使用されるクッキー、オプトアウトの方法を記載します。

8. お子様

当サイトは14歳未満のお子様を対象としておらず、お子様の個人情報を意図的に収集することはありません。

9. 苦情

韓国にお住まいの場合は、個人情報侵害申告センター(privacy.kisa.or.kr、118)または個人情報紛争調停委員会(kopico.go.kr、1833-6972)にもご相談いただけます。

10. 変更

本ポリシーに重要な変更がある場合は、新しい施行日とともに新版をここに掲載します。現行版：2026-10-20。
